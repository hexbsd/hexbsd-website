Everything You Need

Comprehensive FreeBSD server management from your Mac

ZFS Management

Create, manage, and monitor ZFS pools and datasets. Snapshots, clones, and properties at your fingertips.

Jail Management

Create, start, stop, and configure FreeBSD jails. Full control over jail networking and resource limits.

Package Management

Install, update, and remove packages with pkg. Search repositories and manage dependencies easily.

Service Control

Start, stop, restart, and enable services. View service status and manage rc.conf entries.

bhyve VMs

Manage bhyve virtual machines. Create, configure, and control VMs with integrated VNC viewer.

Boot Environments

Create and manage ZFS boot environments. Safe system updates with easy rollback capability.

Users & Groups

Manage system users and groups. Create accounts, set permissions, and configure NIS domains.

Firewall Management

Configure PF firewall rules. Manage network security with an intuitive interface.

Network Configuration

Configure network interfaces, routing, and DNS. Visual network management made simple.

Log Viewer

View, search, and download system logs. Real-time log monitoring with powerful filtering.

File Browser

Browse remote filesystems with ease. Upload, download, and manage files over SFTP.

Integrated Terminal

Full-featured terminal emulator built-in. Drop to the command line whenever you need it.

Poudriere

Manage Poudriere build jails and ports trees. Monitor package builds in real-time.

Security Auditing

Check for vulnerable packages and security advisories. Stay informed about potential threats.

Real-time Monitoring

Monitor active connections and user sessions. Keep track of who's doing what on your servers.
